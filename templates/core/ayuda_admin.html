Administrador

Rol de administración total: gestiona usuarios, mantiene los datos maestros (alumnos, carga histórica) y dispone de todos los permisos del Inspector General.

Crear un usuario

  1. Ve a Configuración → Usuarios y pulsa Nuevo usuario.
  2. Completa nombre de usuario (minúsculas), nombre, apellido y correo.
  3. Define la contraseña dos veces: mínimo 8 caracteres, no muy común ni solo números.
  4. Marca los roles: Inspector General · Inspector · Profesor · Director (combinables).
  5. Pulsa Guardar. El usuario puede entrar de inmediato.

Editar usuario / restablecer contraseña

  1. Lápiz: cambia datos, roles o desactiva el acceso (sin borrar su historial).
  2. Llave: define una nueva contraseña; la anterior queda invalidada al instante.
Protección: no puedes desactivarte ni quitarte el perfil de administrador a ti mismo.

Importar alumnos desde Excel

Sección Alumnos → Importar Excel. Columnas esperadas:

ColumnaContenidoObligatorio
ANombre (MAYÚSCULAS)Sí
BApellido (MAYÚSCULAS)Sí
CCurso (ej.: 1° BÁSICO)Recomendado
D–FRUT · Apoderado · TeléfonoNo
Alumno existente (nombre + apellido + año) se actualiza, no se duplica.

Cargar registro histórico

  1. Alumnos → Cargar Registro Histórico: descarga la planilla base (.xlsx) con hojas Retiros, Atrasos, Uniformes, Celulares y Visitas.
  2. Respeta formatos: fechas AAAA-MM-DD, horas HH:MM, nombres en MAYÚSCULAS, valores SI/NO.
  3. Sube el archivo: los alumnos inexistentes se crean automáticamente.
  4. Si hay filas con problemas, descarga el Excel de errores, corrige y vuelve a subir solo esas filas.
